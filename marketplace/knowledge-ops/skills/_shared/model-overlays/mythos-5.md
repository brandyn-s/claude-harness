# Mythos 5 Runtime Overlay

- Use the exact effective model identifier in automated qualification.
- Treat Mythos 5 as a limited-availability Project Glasswing model; verify
  account entitlement before routing work to it.
- Its capability, pricing, always-on adaptive-thinking, and 30-day-retention
  contracts match Fable 5. It is unavailable under ZDR.
- Mythos 5 does not use Fable 5's safety classifiers. Do not infer from that
  difference that authorization, data handling, or acceptance gates are looser.
- Record provider, context class, effort, and any switch/fallback explicitly.
