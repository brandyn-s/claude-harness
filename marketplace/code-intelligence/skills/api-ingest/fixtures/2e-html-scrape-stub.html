fixture-2e API

Minimal HTML doc-site stub for Phase 2e (Firecrawl fallback) manual verification.

Authentication

All endpoints require a bearer token in the Authorization: Bearer {token} header. Generate tokens at api.example.test/settings.

Endpoints

GET /widgets

List widgets. Cursor-paginated. Max page size: 100. Default: 25.

POST /widgets

Create a widget. Body: { "name": "<string>" }.

Rate Limits

100 requests/minute default. 1000 requests/minute for enterprise.

Errors

Errors return JSON: { "error": { "code": "...", "message": "..." } }.
