## refutation-is-an-active-claim-that-something-is-false

```
WHY: refutation is an active claim that something is false. It
     requires sources that contradict the claim. Absence of supporting
     sources is not contradiction — it's silence.
```

## i-searched-and-didn-t-find-reveals-the-search

```
WHY: "I searched and didn't find" reveals the search's coverage, not
     the world's contents. The search may have used wrong queries,
     wrong domains, wrong date ranges, wrong terminology. Treating
     negative search results as world-truth is a category error.
```

## no-published-evidence-doesn-t-mean-the-claim-is

```
WHY: "no published evidence" doesn't mean the claim is wrong. It
     means the experiment hasn't been run. For practitioners, that
     can be opportunity. Don't close investigation by misclassifying.
```
